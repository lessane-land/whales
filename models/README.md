# Models

Open-licence 3D models from Sketchfab, baked by `tools/bake/` into one clean geometry each: head toward -x,
length 1, centred, simplified where the original was heavy. Their textures are not used: the site paints them
in cel shading with its own palette, so every species shares one look. Each one is credited by title, author,
licence and link in the site's credits sheet. The site is non commercial.
